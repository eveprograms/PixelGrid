# **PixelGrid**

 <a href="https://evepanzarino.github.io/pixelgrid"> <b>PixelGrid App — Live Project</b></a>

## Upcomimg Features
- line tool — click start of line click to end of line
- shape tool - square 
- paint bucket
- timeline to make animations
- save to as a local file on server with user folders tied to database for user retrival
- Select and group pixels to create objects that can be moved
- basic game engine
